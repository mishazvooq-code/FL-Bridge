# FL-Bridge — это легкий VST3-плагин (мост), созданный на C++ и JUCE.

# В чём фишка:
Обычно Image-Line заставляют запускать всю FL Studio целиком как плагин внутри других DAW (Bitwig, REAPER и т.д.). Идея FL-Bridge — подгружать .dll файлы конкретных нативных плагинов FL Studio (например, Sytrus или Harmor) напрямую из папки с установленной FL, без запуска самого тяжелого хоста.

# Как это работает под капотом:

1. Плагин открывается в твоей DAW как обычный VST3.

2. В интерфейсе ты указываешь путь к .dll файлу плагина из папки Plugins\Fruity в директории FL Studio.

3. Мост выдергивает функцию CreatePluginInstance из Image-Line SDK, инициализирует плагин и сразу пробрасывает его интерфейс, MIDI и звук в твою текущую DAW.

4. Сборка завязана на GitHub Actions, чтобы плагин автоматически компилировался в облаке под Windows без мучений с консолью на компе.

# Как установить:
Для установки нужно скомпилировать код
  ### Автоматическая сборка (GitHub Actions)
1. Загрузите код в свой репозиторий GitHub.
2. Перейдите во вкладку **Actions**.
3. Запустите workflow **Build VST3**.
4. Заберите готовый `.vst3` из раздела **Artifacts**.

  ### Локальная сборка (Windows)
```bash
git clone [https://github.com/ВАШ_НИК/FL-Bridge.git](https://github.com/ВАШ_НИК/FL-Bridge.git)
cd FL-Bridge
cmake -B build -A x64
cmake --build build --config Release```
